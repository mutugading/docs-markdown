# open-questions.md — the one register for both modules

Every unanswered question for the Exim doc set lives here, so nobody has to guess which document
holds the current state of a decision. `PRD EXIM.md` cites these ids directly.

Blocks:

| Block | Topic | Owner to answer |
|---|---|---|
| **Q** | Shipment Control (the migration) — carried over from `gap-analysis.md` §6 | Finance + IT |
| **S** | Sales / ESC sourcing | Sales, Marketing |
| **D** | Data and master-data semantics | Master data owner + IT |
| **F** | Finance and accounting | Finance (AP + tax) |
| **O** | Operations and ownership | Import, Export, Purchase |

Rules for this file: a question is **closed** by writing the answer into the document it blocks,
then moving its row into §6 here with the date and who decided. Do not delete rows — a decision
whose reasoning is lost gets re-litigated six months later.

Back-dating is the better accounting on paper — it restates the month the accrual really belonged to — and it is also the answer that stops working exactly when it is needed: the ERP refuses a posting into a closed period, and an accrual nobody billed is usually noticed months later, by which time nothing can be done about it at the screen. `CURRENT` always posts.
