📥 Template & Format Reference

Excel Template Requirements

Template Excel harus mengikuti struktur kolom standar:

  • TYPE (required) — Module code: MIS, SALES, HR, INV, OPEX, PROD
  • GROUP_1 (required) — Top-level category, e.g., EBITDA, NET PROFIT
  • GROUP_2 (optional) — Sub-category, e.g., INCOME, PRODUCTION COST
  • GROUP_3 (optional) — Detail line item, e.g., LOCAL SALES
  • PERIODE_GRAIN (required) — DAILY / MONTHLY / QUARTERLY / YEARLY
  • PERIODE (required) — YYYYMM untuk monthly, YYYY-MM-DD untuk daily
  • VALUE (required) — Numeric, negative allowed (accounting convention)
  • UOM (optional) — USD, HOURS, PCS, PERSON
